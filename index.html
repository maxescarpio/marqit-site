Buddies

Add a buddy from the Play tab.

When you both make the same pick and it’s correct, you each get +25.

Opposite picks earn no bonus.

Rivals

Add a rival from the Play tab. You each start with 5 golden stars.

Whoever gets more of the day’s calls right takes a star from the other.

A tie changes nothing. A 5-day streak earns an extra star.
