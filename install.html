Add Marqit to Your Site in 2 Minutes

One line of code puts a one-tap prediction on your stories. Readers vote YES or NO, see where everyone else landed, and talk it out in the comments. We write the questions, host everything and moderate the comments. You don't have to do anything after setup.

Your code

This is the only thing you need. Paste it once, and it works on every article.

<script async src="https://playmarqit.com/embed.js" data-site="YOUR_SITE_KEY" data-mode="auto"></script>

Your site key arrives in the email we send you. Where it says YOUR_SITE_KEY, paste your key. If you opened a personal setup link from us, it is already filled in.

Set it up

  1. Paste the code once, site-wide

    Put it in the part of your site that appears on every page, usually called the footer or code injection. The table below shows where that is on common platforms. WordPress users can skip the pasting and use our plugin.

  2. That is it

    We write a question for each new article and you never have to touch anything again. The widget places itself inside your articles, after the second or third paragraph. It ignores your home page and anything that is not an article.

    At first, we check each question before it appears, so a new story may take a little while to show the widget. You do not need to do anything.

  3. Check that it works

    Open a story and refresh the page. After we approve the question, you should see the Marqit box with YES and NO buttons. If you do not, see "If it does not show up" below.

Menu names change now and then, so treat these as a guide. If you get stuck, send us a screenshot.

Want more control?

Everything below is optional. Add these to the same line of code.

  • Only some sections: add data-paths="/news/,/sports/" and it only runs on addresses that start with those.
  • Skip some sections: add data-exclude="/video/".
  • Pop-up in the corner instead of inside the article: change data-mode="auto" to data-mode="popup".
  • Just one article, or one exact spot (such as your sidebar): remove data-mode="auto" and paste the line where you want the widget. We set that page's question by hand.

Good to know

  • Free to play, nothing to buy. No ads, no prizes, no money and no gambling in the widget.
  • No cookies and no tracking. It saves one anonymous random ID in the reader's browser so each person's vote counts once. No names, emails or ad tracking. If you serve readers in the EU or UK, mention this in your privacy policy.
  • Fast. It loads after your page finishes, so it does not slow your site down.
  • Works on phones. The widget adjusts to the screen and the pop-up fits small devices.
  • We moderate the comments. New comments are checked before they show, links are blocked, and readers can report anything. You can ask us to turn the widget off at any time.
  • Easy to remove. Delete the line of code and it is gone.

If it does not show up

  1. The question is waiting for our approval. This is the most common reason on a brand-new story. It usually appears within a day.
  2. The page is not an article. The widget skips home pages, lists of stories and other pages that are not a single article.
  3. The page address changed. We match each question to the article's web address. If you change a story's link, tell us.
  4. An ad blocker is hiding it. Try a private window with extensions off.
  5. The platform removed the script. Some editors strip code from posts. Use one of the options in the table above, and put the line in the site header or footer, not inside a story.
  6. Not sure which of these it is? Run the free setup check. Paste an article link and it tells you what is wrong. You can also add ?mqdebug to the end of an article's address to see a note from the widget itself.
