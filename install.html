Add Marqit to Your Site in 5 Minutes

One line of code puts a one-tap prediction on your stories. Readers vote YES or NO, see where everyone else landed, and talk it out in the comments. We write the questions, host everything and moderate the comments. You don't have to do anything after setup.

Your code

This is the only thing you need. It is the same on every page.

<script async src="https://playmarqit.com/embed.js" data-site="YOUR_SITE_KEY"></script>

Your site key arrives in the email we send you. Where it says YOUR_SITE_KEY, paste your key. If you opened a personal setup link from us, it is already filled in.

Set it up

  1. Paste the code where you want the widget

    Pick one of the three layouts. Each one is the same line with a small change.

    A. Inside the article (simplest). Paste the code where the widget should appear, for example after the first or second paragraph.

    B. In your sidebar. Give your sidebar box an id (for example marqit-slot), put the code anywhere on the page, and add data-target="#marqit-slot":

    <script async src="https://playmarqit.com/embed.js" data-site="YOUR_SITE_KEY" data-target="#marqit-slot"></script>

    C. As a pop-up in the corner of the screen. Readers can close it, and it shrinks to a small "Make the call" tab:

    <script async src="https://playmarqit.com/embed.js" data-site="YOUR_SITE_KEY" data-mode="popup"></script>

    For a pop-up on the left, add data-position="left". To change when it appears, add data-delay="8" (seconds).

  2. Put it on your article template once

    Add the line to your article page layout so it appears on every story. You do not need to edit each article. A page only shows the widget when we have set a question for it, so adding it everywhere is safe.

  3. Send us your stories

    Email the links to help@playmarqit.com (a list is fine). We write the question for each one and it appears on that page by itself, with nothing to change on your side. If you would like to approve questions first, tell us and we will send them for a quick yes before they go live.

  4. Check that it works

    Open one of your stories and refresh the page. You should see the Marqit box with YES and NO buttons. If you do not, see "If it does not show up" below.

Where to paste it on common platforms

Menu names change now and then, so treat these as a guide. If you get stuck, send us a screenshot.

PlatformHow
WordPressIn the post editor, add a Custom HTML block and paste the code. To add it to every post, use your theme's footer or a "header and footer scripts" plugin.
GhostSettings, then Code injection, then Site footer. Or add an HTML card inside a post.
SquarespaceAdd a Code block to a page. Site-wide code lives under Settings, Advanced, Code Injection (a Business plan or higher is needed).
WebflowAdd an Embed element, or paste it into the page's Custom Code before the closing body tag.
Custom or hand-built sitesPaste the line into your article template, just before the closing </body> tag.
Substack, MediumThese block outside scripts on posts, so the widget cannot run there.

Good to know

  • Free to play, nothing to buy. No ads, no prizes, no money and no gambling in the widget.
  • No cookies and no tracking. It saves one anonymous random ID in the reader's browser so each person's vote counts once. No names, emails or ad tracking. If you serve readers in the EU or UK, mention this in your privacy policy.
  • Fast. It loads after your page finishes, so it does not slow your site down.
  • Works on phones. The widget adjusts to the screen and the pop-up fits small devices.
  • We moderate the comments. New comments are checked before they show, links are blocked, and readers can report anything. You can ask us to turn the widget off at any time.
  • Easy to remove. Delete the line of code and it is gone.

If it does not show up

  1. We may not have set a question for that page yet. This is the most common reason. Email us the link and we will add it.
  2. The page address changed. We match each question to the article's web address. If you change a story's link, tell us.
  3. An ad blocker is hiding it. Try a private window with extensions off.
  4. The platform removed the script. Some editors strip code from posts. Use one of the options in the table above.

Still stuck? Email help@playmarqit.com with the link to the page and we will fix it.
